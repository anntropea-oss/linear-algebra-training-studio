# Learner Submission Flow

Issue: #4

The active homework panel now includes a learner submission workbench.

## Captured Evidence

- assignment ID
- problem ID
- skill ID
- submitted answer
- score
- confidence before
- confidence after
- hints used
- misconception category
- feedback
- submission timestamp

## Current Scoring

The current scoring pass is intentionally simple and transparent. It compares learner answer text against solution keywords and adjusts for hints used.

This is not a final grading engine. It is a record-making engine for the MVP. Rubric-based grading and instructor review should replace or supervise automated scoring before real learners use it.

## Learning Effects

Submitting work updates:

- attempt log
- activity log
- skill mastery
- confidence
- correction queue when needed
- persisted browser snapshot
