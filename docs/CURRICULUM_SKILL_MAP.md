# Curriculum Skill Map

The rebuilt tutor uses a compact concept path that can expand over time.

## Concept Path

1. Vectors and Linear Combinations
2. Span and Linear Independence
3. Systems of Equations
4. Row Reduction and Rank
5. Matrices as Transformations
6. Subspaces, Basis, and Dimension
7. Orthogonality and Projections
8. Eigenvalues and Eigenvectors

## Starting Points

The learner can start at:

- Brand new: vectors
- I can solve equations: systems
- I know matrices: transformations
- Advanced review: eigenvalues

Earlier concepts are not skipped forever. If a later answer reveals a prerequisite gap, the next repair set can pull the learner backward.

## Lesson Structure

Every concept now starts with theoretical grounding before problem sets:

- big idea
- why it matters
- core definitions
- theory notes
- worked example
- readiness checks

The goal is to teach the mental model before asking for computation.

## Mastery Bands

- 0-39: repair
- 40-59: fragile
- 60-79: growing
- 80-100: secure

## Problem Types

Each concept should eventually include:

- direct computation
- explanation
- misconception detection
- transfer
- challenge

The current problem bank is intentionally small and verified by hand so the feedback loop is trustworthy.
